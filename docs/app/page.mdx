# @opensourceframework

Maintained, compatibility-first forks of important Next.js and React packages.

## Mission

Our goal is to provide a safe, stable, and modernized ecosystem for developers who rely on popular packages that have been abandoned or are no longer actively maintained. We prioritize:

- **Compatibility**: Drop-in or near-drop-in replacements for original packages.
- **Modernization**: Full support for the latest versions of Next.js (including App Router) and React.
- **Security**: Proactive patching of vulnerabilities.
- **Unified Tooling**: Consistent build and test standards across all packages.

## Core Packages

- **@opensourceframework/next-auth**: Modernized v3 legacy fork.
- **@opensourceframework/next-seo**: The standard for SEO in Next.js, kept up-to-date.
- **@opensourceframework/next-pwa**: Reliable PWA support for Turbopack.
- **@opensourceframework/critters**: Optimized CSS inlining.
- **@opensourceframework/next-iron-session**: Edge-compatible session management.

## Getting Started

Each package is available under the `@opensourceframework` scope on npm.

```bash
npm install @opensourceframework/next-seo
```

Check the individual package documentation for specific migration guides and usage instructions.
