# Security Audit Reports

This directory contains security audit reports for all OpenSource Framework packages.

## Audit Reports

Reports are generated by running `./scripts/security-audit.sh`.

### File Naming Convention

- `audit-report-[timestamp].md` - Human-readable markdown report
- `audit-summary-[timestamp].json` - Machine-readable JSON summary

## Running Audits

```bash
# Audit all packages with low+ severity
./scripts/security-audit.sh

# Audit with moderate+ severity only
./scripts/security-audit.sh --level moderate

# Audit specific packages
./scripts/security-audit.sh --packages next-csrf,next-images

# Audit and attempt to fix
./scripts/security-audit.sh --fix
```

## Audit Levels

- **low**: All vulnerability levels
- **moderate**: Moderate, high, critical
- **high**: High and critical only
- **critical**: Critical only

## CI/CD Integration

Add to your CI pipeline:

```yaml
- name: Security Audit
  run: |
    ./scripts/security-audit.sh --level moderate
```

Fail the build on critical/high vulnerabilities.

## Monitoring

- Run audits weekly
- Enable Dependabot on GitHub
- Subscribe to npm security advisories
- Monitor OSS Index / Snyk
